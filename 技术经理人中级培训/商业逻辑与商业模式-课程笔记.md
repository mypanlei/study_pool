# 商业逻辑与商业模式

> **主讲人**: 高延庆
> **课程**: 技术经理人中级培训
> **形式**: 线上会议（存在网络波动）
> **核心观点**: 商业逻辑是商业模式的"道"，商业模式是商业逻辑的"术"

---

## 一、商业逻辑 vs 商业模式：道与术的关系

### 商业逻辑（道）
- 商业活动的**底层原理**与运行机制
- 强调**因果关系的自洽**与商业价值的可行性
- 好比计算机的**操作系统**——是价值创造的基础
- 必须经得起推敲，逻辑不牢如大厦地基崩塌

### 商业模式（术）
- 基于商业逻辑的**具体业务开发框架**
- 好比运行在操作系统之上的**应用程序**
- 需要回答：我是做什么的、如何赚钱、如何触达市场

### 关键辨析
- 商业模式必须建筑在**独特的商业逻辑**之上
- 缺乏逻辑支撑的模式如同空中楼阁
- 商业逻辑是坐标系中的**X轴（内在逻辑）+ Y轴（外在环境）**，商业模式是动态曲线而非静态模型

---

## 二、商业逻辑的四大要素

### 1. 需求 —— 商业活动的起点
| 维度 | 要点 |
|------|------|
| **真实需求 vs 伪需求** | 共享单车"地铁最后一公里"被判定为伪需求，导致行业大规模倒闭 |
| **现实需求 vs 潜在需求** | 经济下行导致消费紧缩，需精准预判市场需求变化 |
| **支付能力是基础** | 空有需求而无消费力只是空中楼阁 |
| **需求分类** | 刚性需求、潜在需求、偶发需求（如世界杯观赛具有情境依赖性） |
| **经济波动影响** | 经济环境对需求弹性有显著影响 |

**案例：共享单车的伪需求警示**
- 看似解决地铁最后一公里，但商业模式不成立
- 需求强度决定商业化成败
- 大量企业因伪需求而倒闭

**案例：罕见病药物 vs 支付能力**
- 30万/疗程的遗传病药物 vs 农村低收入患者
- 5万目标患者中多数是无力承担的弱势群体
- 单纯市场机制在此类孤儿药领域可能失效
- 破局方向：药企CSR合作、慈善合作（如诺华90万白血病药）

### 2. 市场 —— 有需求便有市场
- 形成由**研发、生产、流通**等多方参与者构成的商业生态
- 市场分析需关注行业增长的**多重驱动因子**（市场、政策、经济水平等）
- "钱包有钱"是消费动机的朴素表达

### 3. 交易 —— 商业必须是闭环的
- 通过交易实现**价值交换**和**回本**
- 没有交易如同计划经济下的物质分配，形不成商业

### 4. 增长与盈利
- 分析行业增长的**驱动因子**
- 确保商业增长与盈利路径的结合
- 商业逻辑需要具备**动态调整能力**

## 三、商业模式的六大核心问题

### Q1: 我是干什么的？
- 明确自身定位与业务范围
- 基础设备领域投入大（如铁塔公司），运营服务投入较小

### Q2: 我解决了什么问题？
- 清晰阐述产品为客户带来的价值点
- 价值必须**量化**：提升效率、增加营收、降低成本
- **最优解**：同时实现增收和降本

### Q3: 需求是否真实？
- 必须通过**客户验证**
- 三验证：客户访谈确认痛点、明确价值点、评估支付能力
- 确认需求是现实的、潜在的还是偶发的

### Q4: 我有什么优势？
- 将**核心能力**转化为**商业上的竞争优势**
- 核心竞争力必须转化为商业优势——这是技术变现的关键痛点
- **警惕**：便利店说明无门槛行业的脆弱性

### Q5: 进入门槛在哪里？
- 技术、法规、牌照等护城河形式
- **光伏教训**：专有技术沦为通用技术 → 恶性竞争
- 中国行业惯于将专有技术通用化 → 光伏、锂电池、新能源车陷入低门槛混战
- 马斯克原计划推进37瓦光伏项目，受限于美国严格的知识产权连带责任制度而搁置

### Q6: 收入来自哪里？
- 明确商业模式的收入来源
- 产品差价、服务费、第三方分成等
- **盈利结构的选择**：赚产品差价、服务收入还是两者兼得

## 四、商业模式的四大架构模块

### 1. 采购模式
- 关注上游供应链的**稳定性、可控性及成本**
- 上游产业成熟度对技术规模化的关键影响
- **单一供应商风险**：议价权失衡（以英特尔被迫授权AMD为例）
- **关键材料风险**：稀土铟、白金等全球储量限制可能成为产业瓶颈
- 光伏、氢能源汽车：材料稀缺性导致成本飙升
- 上游成本波动和良率问题直接影响采购策略

### 2. 生产模式
- 技术**可靠性**优先于先进性（商业化场景的核心原则）
- 工艺成熟度及**规模化生产能力**
- **三种模式**：
  - 核心部件自产 + 外包的**混合模式**
  - 全外包的**集成模式**
  - 医疗行业特有的**注册人委外模式**（研发与生产分离）
- 技术诀窍和工艺参数是核心价值，缺乏独特性导致竞争力缺失

**案例：四川长虹押注等离子失败**
- 技术路线选择至关重要
- 技术决策失误可能导致全盘皆输

### 3. 营销模式
- 核心在于能否**有效触达目标客户**
- 确认客户有**支付能力**
- 瞄准有支付能力的客户群体

**案例：特斯拉直销 vs 传统4S店分销**
- 特斯拉直销模式：信息高效传递 + 客户参与感
- 国内仍依赖传统渠道
- 苹果发布会：通过持续曝光建立认知 → 线下体验需求

**案例：罕见病药物的市场困境**
- 5万目标患者中多数支付能力不足
- 市场容量不足导致商业模式失效

### 4. 盈利模式

#### 盈利方式选择
- **产品差价**（传统模式）
- **服务费**（订阅制、会员制）
- **第三方分成**（广告变现等）
- **产品差价 + 服务收入**（双轨制）

#### 案例：苹果的盈利模式
- **市场定价法**（调研后定9000元）vs 国内**成本定价法**
- 苹果直接抽取**30%利润**，剩余由供应链分配
- 通过迭代产品培养忠实用户 → 品牌溢价能力
- 品牌忠诚度对定价权的支撑作用

#### 案例：Costco 会员制
- **核心逻辑**：不赚产品差价，收取会员费
- 精准切入中产阶级对**质量稳定、价格适中**的需求空白
- 会员规模 → 成本摊薄
- 严格品控建立差异化优势
- 快速扩张 → ROE提升
- 特斯拉倒逼沃尔玛开设山姆店——竞争对冲

#### 订阅制 vs 买断制（中外差异）
- 中国用户偏好**买断制**（Office买断价3000元）
- 订阅制（98元/月）接受度低
- 特斯拉FSD：中国改为6万元终身买断，美国采用月费模式
- **凸显本土化策略的重要性**

#### 复购机制设计
- 商业模式需要创造**复购机会**
- **技术缓慢释放策略**：苹果分代发布手机、宁德时代研发多种电池技术
- 一次性交付所有价值 → 客户流失
- **提高用户迁移成本**构建商业闭环

## 五、商业模式的动态调整

### 为什么需要动态调整？
- 商业逻辑和商业模式受到多种内外部因素影响
- 商业模式是**动态曲线**而非静态模型

### 调整因素

#### 时态变化
| 因素 | 表现 |
|------|------|
| **经济周期** | 增长/疲软——当前经济下行对消费行业的冲击 |
| **政策变化** | 法规趋严/放松——环保法规随经济环境波动而松动 |
| **技术突破** | 突破/遭遇瓶颈——人形机器人商业化需突破技术瓶颈 |

**案例：互联网泡沫类比当前AI行业**
- 技术热潮与商业变现的脱节是潜在风险点
- AI泡沫是否破裂取决于商业化进度
- 若变现不及预期可能引发新一轮金融危机
- 英伟达10万亿市值的线性增长逻辑
- 美光可能成为下一个巨头（前提是替代GPU核心功能）
- 技术拐点与市场拐点的交汇至关重要

#### 范式转换
- 由**颠覆性技术**出现导致旧有逻辑被打破
- AI算力一体化可能颠覆GPU市场
- 范式转换时商业模式必须快速响应

#### 行业周期
**案例：白酒行业**
- 临界点效应
- 白酒扩产的反例——周期判断错误导致损失
- 中国白酒、美容等传统行业股价下跌

#### 政策与基础设施变革
**案例：第六代通信（空天地一体化）**
- 6G卫星能实现全球覆盖且无需地面基站
- 中国成立北京信网和上海云鑫两家公司负责未来通信建设
- 战略重心从航天派调整为移动系 → 向运营商倾斜
- 需平衡商业卫星部署与传统基站建设
- 对华为等传统通信企业的潜在冲击

### 调整原则
- 商业模式需要具备**灵活性**
- 根据情景变化**及时调校和迭代优化**
- 商业逻辑需随关键规则变化及时调整
- **四要素**：适配性、灵活性（动态调整）、行业趋势敏感性、持续迭代
- **产品验证三步**：客户访谈确认痛点 → 明确价值点 → 评估支付能力

## 六、项目价值评估与分类

### ABC三类价值项目

| 类别 | 特征 | 商业吸引力 |
|------|------|------------|
| **A类** | 同时提升效率 + 降低成本 | ⭐⭐⭐ 最具吸引力 |
| **B类** | 增加营收但可能提高成本 | ⭐⭐ |
| **C类** | 不提升效率但降低成本（如环保项目，受法规驱动） | ⭐ |

- 核心：技术对客户的实际贡献是什么？
- 若三类均未达标 → 项目失效

## 七、特殊/前沿领域的商业模式探讨

### AI行业的切入选择
- 明确是做**基础设施、大模型还是应用落地**
- 从大模型到关节部件甚至机器人测速站等细分机会
- 商业化场景：技术可靠性优先于先进性

### 人形机器人的商业化反思
- 功能性应优先于人形设计
- 关节等部件显著增加成本
- 目前更像表演性质
- **争议商业模式**：向地方政府出售机器人 → 建立数据采集中心 → 数据卖回给机器人公司（自我循环缺乏实际商业价值支撑）
- 自来水数据打包发债——数据资产化操作可能存在泡沫风险

### 医疗行业的"错位闭环"
- 消费决策者（医生）、支付方（医保）、使用者（患者）**三方分离**
- 甲状腺手术6000元医保定额 → 医院成本控制与医保支付的矛盾
- 电商平台：消费决策者 = 支付者 = 使用者（三方合一，最理想的闭环）
- 支付端改革 + 竞争壁垒 = 可持续盈利

### 共享住宿平台（Airbnb案例）
- **供给端**：全球闲置房源（释放资产价值）
- **需求端**：追求本土体验的旅行者（解决信息不对称）
- **信任机制**：保险保障 + 标准化服务
- **双边收费策略**：
  - 房客：14%（基于旅行体验的价值评估）
  - 房东：3%（侧重资产利用率）
- 平台收入：交易抽取20%-30%

### 核电机器人案例（杭州某企业）
- 早期依赖单一客户（中广核）的5亿订单
- 虽成功上市但产业化基础薄弱
- "研究性收入"不可持续
- **警示**：警惕表面繁荣下的结构性缺陷

## 八、技术商业化的关键原则

### 技术落地的三个核心
1. **规模化生产能力**——降本
2. **团队执行可靠性**——明确实施主体
3. **技术外延性**——多场景应用降低风险

### 逆向投资方法论（市场优先）
1. 评估市场规模和用户支付能力
2. 反推技术实现路径
3. 匹配执行团队

### 两条红线
- 反对纯技术导向的"跪大师"模式
- 必须通过"技术可行性"和"市场需求"双向验证

### 供应链风险管控
- 多供应商策略避免议价权失衡
- 上游材料稀缺性对产业的制约
- 自主可控与成本效率的平衡

---

## 九、商业模式的可持续性验证

### 三个基本验证
1. 明确解决什么问题（客户痛点）
2. 客户是否有支付能力（市场现实）
3. 商业模式能否持续盈利（可持续性）

### 可持续发展要素
- **适配性**：与市场环境匹配
- **灵活性**：动态调整能力
- **行业趋势敏感性**：避免周期误判
- **持续迭代**：不断优化

### 警示信号
- 无门槛业务 → 恶性竞争
- 单一客户依赖 → 产业化基础薄弱
- 表面繁荣下的结构性缺陷
- 数据资产化的自我循环（缺乏实际商业价值）
