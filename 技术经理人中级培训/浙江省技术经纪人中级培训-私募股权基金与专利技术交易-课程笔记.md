### 一、基金基础概念与类型

#### 1. 基金的基本运作机制

基金是一种投资工具，由管理人将投资者的资金集中起来，投向各类资产。资金端分为**个人投资者**和**机构投资者**；资产端投向股票、债券、商品、房地产等各类投资组合。本课程聚焦于**私募股权投资基金**——投向创业企业。

#### 2. 基金的主流类型

| 类型 | 特点 |
|------|------|
| **盲池基金** | 先募集资金，再确定具体投资标的（过去常见） |
| **SPV（单项目基金）** | 明确投向特定标的（当前流行趋势，因明星项目增多，大家围绕单个项目组SPV） |
| **证券投资基金** | 流动性强、周期短、风险与流动性成正比 |

**公募基金细分**：股票型、债券型、混合型、货币型，不同投资标的风险与流动性各异。

**私募股权基金**：流动性极差，单只基金周期5~8年，退出路径有限，风险理论最高（R5级别）。债券型、货币型相对稳健、收益较低，股票型风险较高。

### 二、募投管退：私募股权基金完整生命周期

私募股权基金运作分为四个环节：**募、投、管、退**。

#### 1. 募（募集）
- 确定基金规模、投向、周期、管理费等核心要素
- 向投资者宣讲并募集资金

#### 2. 投（投资）
- 投资团队筛选项目、筛选标的、与标的谈判

#### 3. 管（管理）
- 投后管理赋能：日常跟踪、业务对接、融资对接

#### 4. 退（退出）
- **IPO退出**（最理想）
- **并购退出**
- **回购退出**（相对差一点，至少保本金）
- **清算退出**（最差，本金无归）

### 五、投资流程：项目筛选漏斗

#### 标准四环节
1. **初筛** — 从源头挑项目
2. **立项** — 投资委员会内部全方位交流沟通
3. **尽调** — 第三方或自有风控/法务
   - 国资通常找第三方财务、法务、业务尽调
   - 部分机构自建业务、法务、财务团队尽调
4. **谈判** — 估值、投资额、股东条款（含回购权益），国资监管严格，必须含回购及优先权利

**漏斗效应**：100个项目最终投1-2个，过程繁琐。项目池来源依赖机构资源积累和认知。

### 六、基金类型与投资阶段

| 基金类型 | 投资阶段 |
|----------|----------|
| 天使基金 | 早期、种子轮 |
| VC基金 | 成长期（此前主流） |
| PE基金 | 成熟期 |
| 并购基金 | 近年兴起（IPO退出通道收窄后趋势） |

**风险-收益关系**：越早期风险越大、收益越大。当前趋势是往早期走（VC期项目已达几十亿至几百亿估值，早期项目也不便宜——具身智能/大模型第一轮即5-10亿甚至几十亿）。

#### 半导体投资案例：三家中型机构对比

| 机构 | 特点 | 投资阶段 | IPO表现 |
|------|------|----------|---------|
| **中芯聚源** | 中芯国际产投，Fab厂链主资源，掌握产业链数据 | 全阶段布局，成熟期最多 | IPO成功率极高 |
| **中科创新** | 典型天使/早期基金 | 14-15年起投种子轮、天使轮 | IPO率相对低（早期项目未赶上19-22年退出高峰） |
| **林芯** | 投成熟半导体项目 | 16年起投成熟期 | IPO比例高（赶上科创板红利） |

**关键洞察**：半导体国产化投资从14-15年国家大基金成立开始。19年科创板推出打开了退出通道（19-22年为退出高峰期）。选标的和聚焦方向不同，整体收益差距极大。资本市场IPO窗口具有周期性，踩对周期至关重要。

### 七、投资标的筛选：核心框架

#### "投资投人"的拆解

**两个核心维度**：
1. **赛道方向** — 聚焦什么领域（AI、具身智能、低空经济等）
2. **团队能力** — 以创始人为核心

**四象限分类**：

| | 方向好 | 方向一般 |
|--|--------|----------|
| **团队强** | 可遇不可求（理想标的） | 有增长能活着，但无退出路径（鸡肋） |
| **团队弱** | 需观察是否能从第二梯队跃升至领头羊 | 优先排除 |

#### 行业赛道筛选方法论

**核心关注点：变化**（行业变革点）

**三维度分析**：
1. **宏观（政策）** — 投资大前提，无政策支持基本不可为
   - 反例：教育（20年后无法投）、创新药（科创板亏损标准取消后受阻）
   - 正例：低空经济（23年起国家力推，迅速成为主流赛道）
2. **中观（产业）** — 产业自身演进驱动投资机会
   - 技术驱动型：AI、自动驾驶、AR/VR
   - 模式驱动型：O2O、产业互联网（技术带来的范式变化）
3. **微观（公司）** — 结合宏观中观迭代分析

#### 产业竞争格局分析

**判断产业所处阶段**：
- **新兴阶段** → 聚焦产品/技术
- **快速成长阶段**
- **成熟/洗牌阶段** → 看重市场能力、运营能力、利润与毛利

**方法论**：自上而下研究，微观聚焦需结合宏观和中观持续迭代，这是一个动态持续的过程。

### 八、创始团队评估

#### 两个维度：做事能力 vs 做人能力

| 类型 | 做事能力 | 做人（人品/分享精神） | 评估 |
|------|----------|----------------------|------|

- 20年起投BAT高管和高校老师出现很多坑

### 十、投后管理与退出

#### 精力分配的二八原则
- **20%精力给差项目**（沉没成本，不应过度投入）
- **80%精力给好项目**（好项目团队格局高，赋能同时获得更多资源）

#### 投后服务常见形式
- 资源对接（政府关系、管理咨询、订单、技术人才）
- 早期企业深入辅导（技术型创业对产品/市场/运营的弥补）
- 融资节奏规划和机构对接
- 财务管控（资本下行期，极端情况派财务总监到被投企业）

#### 退出数据
- 头部天使基金IPO比例不到 **2%**
- 创业九死一生，100个项目能成功1个已属不易
- **爆款项目**逻辑：一期基金有一个爆款即可回本（如投中宇树，10亿基金可回本并大赚）
- 20%好项目覆盖大部分收益

#### 收益来源：多重红利叠加
- **产业增长红利**（如半导体）
- **资本市场红利**（具有周期性——创业板09年开板8-10倍收益、科创板19年开板红利、北交所退出路径）
- IPO监管周期处于"放水-关闸"循环中，等不到放水期只能等下一波

#### 并购现实
- 喊得响、真正close的极少
- 核心障碍：一级市场10-20亿项目 vs 二级市场仅给几亿估值，估值差距太大
- 公告100个并购，最终能成4-5个

#### 企业发展规律
- 从设立到IPO通常需 **10-15年**（科创板已加速）
- 0-1、1-10、10-100各阶段均难跨越
- 基金周期5-8年 vs 企业成长周期存在天然错配
- 但此规律正在被打破（见下文）

### 十一、当前投资热点：国家战略方向

#### 冰火两重天的市场
- 大部分方向融不到钱
- 但大模型、具身智能、量子、商业航天、脑机接口方向融资如火箭——"这个月10亿，下个月20亿，再过个月30亿"

#### 国家战略驱动
- **使命驱动、国家战略驱动**，钱涌向未来产业
- 完全对标马斯克的领域，国家队亲自下场
- 政治正确 → 国资决策无风险
- 技术门槛极高 → 院士/知名教授领衔，回到科学家创业模式

#### 估值暴涨案例：灵巧手
- 3月：20-30亿
- 随后：快速到80亿
- 大佬介入后：200亿

#### IPO配给制
- 只有战略方向才给IPO机会，快速达到IPO阶段
- **智谱**（19年成立）：港股上市，6000+亿市值（卖算力收入快速放大）
- **MiniMax**（21年成立）：几千万收入→1000+亿市值
- **摩尔线程**（20年成立，25年上市）：IPO前300亿→上市后2000-3000亿
- **沐曦**（20年成立，25年上市）：亏损较多、收入不多
- **蓝箭**：几千万收入即获IPO

5年上市周期完全颠覆了过去10-15年的规律。资本疯抢头部战略新兴方向项目，估值从30亿→60亿→百亿快速攀升。泡沫何时破灭尚不确定，取决于国家战略意志的延续性。

### 二、专利价值评估的五大因素

> 国家知识产权局列举的高价值专利（有国外同族、获国家金奖、产生经济效益等）都是**事后诸葛亮**。真正的挑战在于：在尚未产生效益、未申请国外专利、未授权之前，如何判断其价值？

#### 因素一：技术因素

| 子维度 | 含义 | 价值影响 |
|--------|------|----------|
| **①配套技术依存度** | 使用该技术是否需要其他配套技术 | 依存度越低 → 价值越高（独立解决问题） |
| **②可替代性** | 市场上有多少替代方案 | 可替代性越低 → 价值越高（非它不可） |
| **③技术成熟度** | 专利与最终产品的距离 | 成熟度越高 → 价值越高（照专利即可做出产品） |

#### 因素二：经济因素

**①市场占有率（市场规模）**
- 技术再先进，若市场规模极小（如一年全球只卖10台），价值有限
- ⭐ **经典案例：宇航员纸尿裤材料**
  - 美国宇航局为解决宇航员小便问题研发了超吸水材料并申请专利
  - 最初市场规模极小（仅十几人使用），专利不值钱
  - 后来应用场景转移到婴儿纸尿裤、老人纸尿布，市场规模扩大上亿倍
  - **技术价值取决于应用场景和市场规模的匹配**

**②市场竞争力与政策适应性**
- 解决同一技术问题往往存在多条技术路线，最终只有一条胜出
- **案例1：电视机技术路线之争（2000年左右）**
  - 高清电视 vs 背投电视 vs 等离子 vs 液晶
  - 液晶胜出 → 其他路线的专利价值归零
- **案例2：汽车技术路线之争（近十年）**
  - 欧美：燃油车；日本：氢能源；中国：电动车
  - 中国发展电动车 → 电车相关专利胜出
  - **政策适应性是市场竞争力的一部分**

#### 因素三：时间因素

专利价值的时点分布呈**倒U形**，**中间段最值钱**（约第7-8年，以20年发明专利为例）：

| 时点 | 价值评估 |
|------|----------|
| 刚申请/未授权 | 能否授权不确定，价值低 |
| 刚授权 | 技术成熟度、市场验证、法律稳定性均未完成 |
| **授权后3-5年（约第7-8年）** | **价值最高** |
| 临近到期（第18-19年） | 等两年即可免费使用，价值极低 |

#### 因素四：人的因素

**同样专利，不同人评估价值天差地别。** 有市场眼光者认为能赚1亿→愿花1000万购买；保守者认为市场规模仅1000万→只愿花100万。10倍差距纯粹取决于买方认知和能力，与技术本身无关。

#### 因素五：法律因素

**"真发明假专利"**——发明创造优秀但专利撰写差劲，导致被无效或被规避，价值归零。

**关键要点：**
1. **隐藏技术秘密**：专利与技术秘密结合，市场竞争力更强，捆绑转让价值更大
2. **扩大保护范围**：优秀代理人应将发明从1放大到3、5、10（概括与引申）
3. **重视从属权利要求**：
   - 独立权利要求往大了写
   - 最后一个从属权利要求缩小到最佳实施例（上市产品）
   - 既防无效、又防规避设计
4. **独立权利要求尽量少写技术特征**——避免写入"非必要技术特征"

### 三、经典案例：周玲频谱仪的教训

**案情**：30多年前，周玲发明频谱治疗装置（利用声光电帮助损伤恢复），专利写道："一种频谱仪，包含A、B、C、D、E、F、G、H和**音乐发声装置**"。

**市场出现仿品**：A、B、C、D、E、F、G、H全有，**唯独没有音乐发声装置**。

**判定：不侵权。** 权利要求要求包含音乐发声装置，仿品少了这一特征，覆盖不了。

**核心概念——非必要技术特征**：拿掉该特征，原装置照样能达到技术效果。将非必要技术特征写入权利要求 = 主动给竞争对手留下规避空间。此即"真发明假专利"的典型。

---

### 四、防止选择发明

**风险**：你申请了大范围的"基础专利"，竞争对手在你的大范围内选了小范围（效果更好），申请"选择发明专利"。你进入小范围还要经对方许可并交费，基础专利价值大幅减损。

**防范方法**：在说明书具体实施方式（实施例部分），尽量多地公开实施例（在不泄露技术秘密的前提下），让对手无法在范围内画出新颖的小范围。

---

### 五、帮助法官认定侵权

**背景**：95%以上审理专利案件的法官是纯法律背景，无技术背景。他们面对抽象的上位概念权利要求和具体的产品零部件，难以对应。

**对策**：**多写从属权利要求，将上位概念下位化、抽象概念具体化。** 例如，权利要求中写"加热装置"，从属权利要求中写"加热装置为微波炉"。竞争对手若用微波炉，法官可一眼认定侵权，无需复杂解释。

### 六、专利尽职调查

#### 为什么做？——评估价值 + 防范风险

#### 什么时候做？——越早越好（谈判前做，不行就不谈了）

#### 调查内容

##### 1. 专利权属调查

**专利证书 ≠ 真实权利人。** 专利证书仅表明授权时的法律状态。授权两个月后，专利权可能已通过著录项目变更转让。

**需警惕的情形**：
- **专利权人是个人** → 调查是否为职务发明（大学教授/研究所人员以个人名义申请）
- **发明人非本公司员工** → 可能涉及共同权利人（与高校或其他公司共有）
- **查看专利登记簿副本**（而非仅看专利证书），了解最新权利人、法律状态、是否被提无效、是否质押、是否转让过
- **防范一女二嫁**：转给A又转给B

**受让方支付能力风险**：里程碑付款（如1000万分付：先100万+后900万），若受让方后续不付款，即使打赢官司，受让方已转给善意第三人则追不回来。

##### 2. 法律状态调查

专利不同法律状态对应不同价值（**越往后价值越高**）：

| 状态 | 说明 |
|------|------|
| 技术秘密（未申请专利） | 有价值但一旦泄露一文不值 |
| 已受理未公开 | 保密状态，公开渠道查不到 |
| 已公开未授权 | 任何人可查到，审查中 |
| 已授权 | 有专利号 |
| 无效中 | 被提无效宣告，有风险 |
| 视撤/主动撤 | 未做动作或主动放弃 |
| 驳回 | 可3个月内提驳回复审 |
| 终止 | 未交年费 |
| 全部无效 | 知识产权视为不存在 |

##### 3. 权利稳定性分析（专利性分析）

需分析专利法最实质性的条款（时间关系未展开）：

###### 新颖性（单独对比）
- 与现有技术的每一个技术相比有不同即有新颖性
- 例：中药配方A+B+C+D+E+F，与现有A+B+C+D+E、A+B+C+D+F等单独相比，均有不同 → 有新颖性

###### 创造性（组合对比）——专利法最难的部分
- 本领域普通技术人员是否容易想到
- 技术效果相差无几但技术方案迥异 → 有创造性
- 技术方案相似但技术效果意料不到 → 有创造性
- 例：A+B+C+D+E与A+B+C+D+F可自然组合出A+B+C+D+E+F且无新功能 → 无创造性

**三性总结**：
- **新颖性**：解决"能不能"——一模一样不能保护
- **创造性**（inventive step）：解决"值不值得"——不仅要不同，不同要有高度
- **实用性**

###### 支持问题（专利法第26条第4款）
- 权利要求书应得到说明书支持：**公开越多，保护越大**
- 例：保护温度范围100-200℃，需在说明书中公开100℃、200℃和中间值（如156℃）三个实施例

###### 公开充分问题（专利法第26条第3款）
- 本领域技术人员无需创造性劳动即可再现
- 三个要点：①能重复 ②能达到所述技术效果 ③仅要求保护的技术方案需公开充分

###### 其他要点
- **必要技术特征**：独立权利要求应记载解决技术问题的所有必要特征
- **保护客体**：发明=方法+产品；实用新型=固定形状构造的产品；外观设计=形状/图案/色彩
- **不授权客体**（专利法第25条）：科学发现、疾病诊断治疗方法、智力活动规则、动植物品种、原子核变换物质
- **修改限制**（专利法第33条）：不能超出原说明书和权利要求书记载范围

### 七、FTO：专利侵权可能性分析

**核心概念**：专利权是**排他权**而非垄断权。即使你是专利权人，生产销售专利产品仍可能侵犯他人专利。

**分析范围**：
- 产品各部件（整体可能不侵权但某个部件侵权）
- 方法各步骤及使用的装置、物质（加热装置、分离装置、原料、催化剂、溶剂等）
- 审查过程中的**所有中间文件**——专利保护范围不仅由权利要求界定，申请和无效过程中讲的每句话、提交的每个修改文件都可能限制最终保护范围

---

### 八、侵权分析三原则

#### 原则一：全面覆盖原则

**对比对象**：涉嫌侵权产品 vs 权利要求书（**不是产品比产品，也不是专利比专利**）

**规则**：将权利要求放在下面，涉嫌侵权产品放在上面。产品能覆盖权利要求中的所有技术特征 → 侵权；缺少任意一个特征 → 不侵权。

**频谱仪案例回放**：
- 权利要求含A、B、C、D + 音乐发声装置
- 产品有A、B、C、D + 音乐发声装置 + 额外E、F → **覆盖→侵权**
- 产品有A、B、C、D → **无音乐发声装置→覆盖不了→不侵权**

#### 原则二：等同原则

以基本相同的手段、解决基本相同的问题、达到基本相同的效果 → 视为等同，仍构成侵权。

**示例**：
- 专利配方：A+B+C+D+**葡萄糖**
- 竞争对手：A+B+C+D+**果糖**
- 果糖与葡萄糖功能效果无实质差异 → 等同侵权

#### 原则三：禁止反悔原则（禁反言）

申请或无效过程中为获得授权所做的**限缩性陈述或修改**，在侵权诉讼中不得反悔扩大。

**示例**：
- 最初申请："A+B+C+D+糖"
- 审查员以含蔗糖的现有技术驳回 → 申请人将"糖"限缩为"葡萄糖"
- 竞争对手使用"果糖"
- 等同原则可能认定果糖=葡萄糖，但**禁止反悔对抗等同**——申请人已放弃"糖"的范围，不得再主张果糖落入保护范围

### 九、技术交易中的法律风险

#### 1. 人的风险

| 风险点 | 防范措施 |
|--------|----------|
| 专利证书不等于真实权利人 | 要求出具**专利登记簿副本** |
| 专利权人是个人 | 调查是否为职务发明 |
| 发明人非本公司员工 | 查明发明人背景及与原单位协议 |
| 受让方无支付能力 | 评估受让方财力，警惕里程碑付款违约 |

#### 2. 交易标的风险

**技术交易的三种标的**：专利、技术秘密、软件著作权

**法律状态与价值关系**：越往后价值越高——技术秘密 < 申请未公开 < 已公开未授权 < 已授权 < 被提无效但维持有效

**同族专利与地域性**：
- 同样发明创造在不同国家申请的专利称为同族专利
- 专利具有**地域性**：在中国申请仅在中国大陆受保护（香港、台湾、澳门需分别申请）
- 若中国专利授权但美国同族被驳回，美国的驳回理由可能被用来在中国无效该专利 → 可据此压价

#### 3. 交易标的行使风险

| 风险 | 说明 |
|------|------|
| **专利与产品的距离** | 第一件电视机专利到产品问世相隔**50年**，距离过大需打折扣 |
| **技术秘密捆绑** | 要求技术秘密一并转让，防止后续加价 |
| **相关专利壁垒** | 实施专利过程中可能用到他人的专利，需额外付费 |
| **FTO侵权风险** | 产品本身、原材料、零部件、工艺是否侵犯他人权利 |

#### 4. 行使类型与方式风险

| 类型 | 含义 |
|------|------|
| **权利转让** | 所有权转移（卖房子） |
| **普通许可** | 许可给被许可人，仍可许可他人，自己也可实施 |
| **排他许可** | 仅许可给被许可人，不可再许可他人，但自己可实施 |
| **独占许可** | 仅被许可人可实施，连专利权人自己也不能实施 |
| **分许可** | 被许可人可再许可给第三方 |
| **交叉许可** | 互相许可，互相不用给钱 |

#### 5. 行使期限风险
- 发明专利20年、实用新型10年、外观设计15年
- 临近到期的专利价值极低
- 投产周期与许可期限匹配：若用2.5年才能投产但只有3年许可 → 仅半年销售期
- 产品生命周期：若产品上市1年即被替代，后续许可期浪费

#### 6. 行使地域风险
- 在不同国家申请专利可大幅提升价值（中国10万→评估100万人民币；美国同族评估100万美金）
- 同一国家可限制许可地域范围（安徽 vs 华东六省一市）

#### 7. 对价与支付风险
- 一次性付 vs 分阶段付
- 按销售额百分比、利润百分比还是按件数付

### 十、专利许可合同的十一项内容

1. **专利技术内容和实施方式**：是否包含技术秘密；实施方式（制造、销售、许诺销售、进口、使用）
2. **许可合同种类**：普通/排他/独占/分许可/交叉许可
3. **有效期限和地域范围**
4. **技术指导和技术服务**：许可费是否包含指导费用
5. **专利权瑕疵担保和保证条款**：专利被无效后的退费和损害赔偿
6. **许可费用和支付方式**
7. **违约赔偿金**
8. **不可抗力**
9. **专利技术改进成果的归属**：改进方所有？原权利人所有？共同所有？
10-11.（其他条款需结合具体交易确定）

### 十一、真实案例：天一公司轮胎技术转让

- **技术**：涂在轮胎内表面的配方和工艺，轮胎被扎破永不漏气，扎后继续行驶1000公里
- **专利布局**：8件中国专利 + 3件外国发明专利 + 7件国内实用新型
- **交易**：新加坡公司出价 **1600万打包**
- **谈判**：从早9点谈到下午4点，仅谈专利权转让合同
- **薛律师忠告**：**模板没有用**——1600万的交易和16万的交易复杂度天差地别，合同模板无法覆盖各种"坑"
