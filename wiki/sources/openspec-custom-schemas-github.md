# OpenSpec Custom Schemas — GitHub Repository

> OpenSpec 自定义 schema 集合仓库，提供默认 spec-driven schema 之外的多种工作流模板。展示了如何为不同交付上下文定制 OpenSpec。

## 核心内容

1. **Minimalist Schema**：最小化路径——从 Spec 到执行，使用 User Story 需求和 Gherkin 风格验收标准。

2. **Event-Driven Schema**：面向事件驱动系统的结构化工作流，集成 Event Storming 发现流程和 AsyncAPI 规范。

3. **Behaviour-Driven Schema**：Proposal-led 工作流，可观察行为驱动设计和实现。Specs 保持 OpenSpec 可合并的 `spec.md` 格式，场景使用 Gherkin 的 GIVEN/WHEN/THEN。

4. **Intent-Driven Schema**：完整提案工作流——proposal → specs → design → adr → tasks。结合可观察行为、技术设计、持久架构决策记录和实现任务。

5. **Spec-Driven With ADR**：实验性工作流，将架构决策记录持久化到目标仓库的顶级 `adr/` 目录。
