# 大语言模型基础（LLM）

> 面向初学者的 LLM 入门教程，涵盖 LLM 本质（基于统计的模式匹配系统）、Transformer 架构核心原理、Prompt 工程基础、以及 API 调用实践（OpenAI/DeepSeek/阿里百炼）。

## 核心内容

1. **LLM 本质** — "极其用功、记忆力超群的学生"，通过海量文本学习语言统计规律，逐词生成文本。
2. **Transformer 架构** — 自注意力机制（Self-Attention）是核心创新，让模型并行处理并深度理解全局上下文。
3. **Prompt 工程入门** — 四要素：上下文（角色与背景）、指令（任务目标）、示例（范例参考）、格式要求。
4. **API 调用实践** — OpenAI（gpt-4o）、DeepSeek（deepseek-v4-flash/pro）、阿里百炼（qwen-plus）的非流式/流式调用示例。
5. **主流大模型列表** — GPT、Claude、Gemini、通义千问、文心一言、智谱清言、Kimi、讯飞星火、DeepSeek、Llama、Grok、MiniMax、百川等。

## 关键概念

- LLM 不是全知全能的，有明确的局限性（知识截止、数学计算、实时信息等）
- 自注意力机制是 Transformer 最关键的创新
- API 参数：Temperature、Top-p/Top-k
