# AI 底层架构

> 展示从基础大模型到智能体应用的完整五层 AI 系统架构：基础层（模型）→ 上下文层（记忆）→ 能力扩展层（工具）→ 智能体层（决策）→ 应用层（行动）。

## 核心内容

1. **五层架构** — 每层的核心组件、核心作用和典型能力。
2. **核心名词释义** — Transformer、Token、Prompt、RAG、MCP、Agent、Tool Calling、Memory。
3. **完整运行流程** — 用户输入 → 记忆增强 → LLM 推理 → Agent 规划 → 工具执行 → 输出结果。

## 关键架构

- 基础层：LLM & Token、Transformer 架构
- 上下文层：Context Window、Prompt、Memory、RAG
- 能力扩展层：MCP、Tool Calling、API、Database
- 智能体层：Agent、Explore、Plan、Act
- 应用层：Agent Skill、Workflow、Automation
