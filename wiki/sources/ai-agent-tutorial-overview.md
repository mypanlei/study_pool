# AI Agent（智能体）教程

> 菜鸟教程 AI Agent 系列的总览页面。定义 AI Agent = LLM（大脑）+ Planning（规划）+ Tool Use（执行）+ Memory（记忆），面向零基础读者介绍 Agent 的基本概念、结构组成和工作原理。

## 核心内容

1. **Agent 定义** — AI Agent 是能够感知环境、进行决策并执行行动的智能软件实体，本质是自动执行任务的程序。
2. **Agent = LLM + Planning + Tool Use + Memory** — 四大核心组件的基础公式。
3. **工作原理** — 通过 Python 伪代码 WeatherAgent 示例演示感知→规划→行动→记忆的完整流程。
4. **与普通大模型的区别** — 普通 LLM 生成文本，Agent 生成行动并执行行动。

## 关键概念

- 目标驱动 vs 对话框问答的思维转变
- 三块结构：目标、逻辑、工具
- 运行方式：多轮连续操作、遇阻时调整执行步骤
