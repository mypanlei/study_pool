# AI Agent 工具与外部集成

> 介绍 Agent 与外部世界交互的三种核心技术：Computer Use（GUI 操作）、MCP 协议（标准化工具接入）和 API 集成（REST/GraphQL/gRPC）。

## 核心内容

1. **Computer Use** — 屏幕截图解析、GUI 元素识别、鼠标/键盘控制、浏览器自动化的完整工作流（观察→理解→决策→执行）。
2. **MCP 协议** — Model Context Protocol 的架构组件（Host/Client/Server）、通信流程和 Python Server 实现示例。
3. **API 集成** — REST API 客户端封装、GraphQL 灵活查询、gRPC 高性能 RPC，以及三种集成方式的最佳实践（错误处理、重试、限流、缓存、安全）。

## 关键概念

- Computer Use 适合无 API 的 GUI 自动化场景
- MCP 是 AI 领域的 "USB 接口"，提供标准化工具接入
- REST API 仍是最主流的 Web API 集成方式
