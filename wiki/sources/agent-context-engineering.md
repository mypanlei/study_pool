# Agent 上下文工程

> 系统介绍 Agent 上下文工程的核心理念和实践方法，涵盖上下文预算管理、系统提示工程化、工具描述优化、历史记录压缩策略、检索上下文质量控制。

## 核心内容

1. **上下文预算管理** — 将上下文窗口视为有限预算，以 200K token 为例给出各层次分配建议。
2. **系统提示工程化** — 五位原则：分层组织、正面表述、提供示例、优先级明确、去除冗余。
3. **工具描述优化** — 精简/精炼/参数约束/分组注册四种策略。
4. **历史记录压缩** — 滑动窗口、阶梯摘要、分层摘要、关键轮标记四种策略对比。
5. **检索上下文质量控制** — 查询改写、相关性过滤、来源标注、长度裁剪。
6. **常见模式** — 渐进式披露、上下文压缩链、上下文水印。

## 关键概念

- 上下文工程不是一次性配置，而是测试→分析→优化→再测试的迭代循环
- 上下文窗口不是越大越好，过多上下文会稀释注意力
- 上下文水印用于调试和监控
