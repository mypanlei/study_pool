# AI Agent 简介

> 菜鸟教程 AI Agent 系列的入门篇，系统介绍 AI Agent 的核心概念、与传统 AI 模型的区别、五大核心特征、发展历程及应用场景。

## 核心内容

1. **Agent = LLM (大脑) + Planning (规划) + Tool use (执行) + Memory (记忆)** — 核心公式的详细解读。
2. **与传统 AI 模型的区别** — 对比表涵盖交互方式、决策能力、工具使用、记忆机制、目标导向、错误处理六个维度。
3. **核心模式：ReAct** — Thought → Action → Observation → Repeat 循环。
4. **五大核心特征** — 自主性、反应性、主动性、社交能力、学习能力。
5. **发展历程** — 概念萌芽期(1950s-2010s) → 深度学习赋能期(2010s-2020) → 大模型 Agent 爆发期(2021-至今)。

## 关键概念

- 感知层、规划模块、记忆模块、工具调用模块
- Agent 类型：单一任务 / 多模态 / 自主 / 模拟 Agent
- 常见挑战：幻觉、边界失控、成本控制、安全隐私
