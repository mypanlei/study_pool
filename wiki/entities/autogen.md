# AutoGen

> 微软开源的对话式多 Agent 框架。擅长模拟多个 Agent 之间的辩论与对话，通过对话驱动任务完成。

## 关键信息

- **类型**: 开源多 Agent 框架
- **开发商**: Microsoft Research
- **语言**: Python
- **核心模式**: 对话式多 Agent 协作
- **定位**: 多个 Agent 之间通过对话协作完成任务
