# LlamaIndex

> 专注于私有数据检索与 LLM 推理结合的 RAG 框架。提供从数据接入（Data Ingestion）到检索增强生成的全套工具链。

## 关键信息

- **类型**: RAG 增强型 AI Agent 框架
- **语言**: Python / TypeScript
- **核心定位**: 私有数据检索 + Agent 推理
- **与前身关系**: GPT Index 改名而来

## 与 LangChain 对比

| 维度 | LlamaIndex | LangChain |
|------|-----------|-----------|
| 核心强项 | 数据连接/索引/检索 | Agent 链/工具编排 |
| RAG 深度 | 深（多种索引策略） | 中 |
| Agent 能力 | 中 | 强 |
| 适合 | RAG 优先的应用 | Agent/Chain 优先的应用 |

## 核心能力

- 多源数据连接器（150+）
- 高级索引策略（树/向量/关键词混合）
- 查询引擎与 Agent 接口
- 可观测性与评估
