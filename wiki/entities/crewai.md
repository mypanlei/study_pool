# CrewAI

> 角色驱动的多 Agent 协作框架。模拟人类团队组织方式（Manager/Worker 等角色），通过角色分工实现任务协作，上手极快。

## 关键信息

- **类型**: 开源多 Agent 编排框架
- **语言**: Python
- **核心模式**: 角色驱动（Role-based）
- **定位**: 模拟人类团队的多 Agent 协作
